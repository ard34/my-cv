# Riski Ardiansyah — Cybersecurity & Web Developer Portfolio

Personal portfolio and interactive CV website for **Riski Ardiansyah** (Cybersecurity Engineering Student at Politeknik Piksi Input Serang).

## 🚀 Features
- **Cybersecurity & Cyber Defense Operations Showcase**: Interactive tools showcase (Kali Linux, Burp Suite, Nmap, Docker, VS Code, Linux, etc.)
- **AI-Assisted Dev Tech Stack**: Codex, Claude AI, Gemini, GitHub, Laravel, Tailwind CSS, Python.
- **Real-World Projects**: ExamBro (CBT Digital Examination), Koperasi Santri (SantriWallet Cashless), BBn Muslim (E-Commerce & Inventory), Wazuh SIEM & Security Log Analysis.
- **Official Credentials & Certifications**: Live certificates with direct verification links.
- **Responsive Cyberpunk UI/UX**: Dark mode aesthetic with cyber shield matrix, glassmorphism, responsive desktop (1440px) to mobile (390px).

## 🛠️ Tech Stack
- HTML5 / Semantic Web
- Tailwind CSS (Cyber Dark Theme)
- Vanilla JavaScript (ES6+ Modular Architecture)
- Lucide Icons & Brand Favicon CDN
- AOS (Animate On Scroll) & Vanilla Tilt

## 💻 Local Development
Open `index.html` directly in any web browser or start a local HTTP server:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
